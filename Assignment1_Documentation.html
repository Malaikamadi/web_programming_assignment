1. Executive Summary & Selected Organisation Profile

For Assignment 1, the selected Sierra Leonean organisation is Django Girls Sierra Leone (Freetown Chapter). Django Girls is a community-powered, non-profit initiative dedicated to bridging the acute gender gap in the Sierra Leonean technology ecosystem by introducing women and young girls to modern programming through free, hands-on workshops.

In Sierra Leone, female participation in computer science and software development has historically faced major hurdles, including limited access to beginner-friendly mentorship, digital infrastructure disparities, and intimidation surrounding technical disciplines. Django Girls Freetown overcomes these obstacles by offering an empowering, supportive, and accessible space where participants transition from complete digital beginners into capable software builders in a single workshop.

The web platform engineered for this assignment delivers the central digital presence for Django Girls Sierra Leone. The solution incorporates dynamic PHP server logic, relational database connectivity, modern responsive UI styling, robust password security, and personalized dashboard management—synthesizing all primary concepts covered during Weeks 1 to 4 of class.

2. Architecture & Web Platform Page Structure

The web application is partitioned into clean, modular components designed around user experience and security:

  • Prominent Logo Display (Header): The official Django Girls logo is positioned prominently at the top header of every page alongside the Sierra Leone national tech badge, establishing instantaneous brand recognition and organizational trust.
  • Home Page (index.php): The public gateway presenting the organisation's mission, impact statistics (500+ girls trained in SL, 100% free), interactive code showcases, live workshop schedules queried dynamically from MySQL, and calls-to-action.
  • Sign-Up Page (register.php): A comprehensive participant onboarding form capturing full name, username, email, phone number, experience level, and preferred learning track, backed by extensive server-side validation and password hashing.
  • Login Page (login.php): A secure authentication portal utilizing PDO prepared statements to query user records, validating entered credentials against hashed passwords, and initializing a protected PHP session.
  • Dashboard (dashboard.php): A personalized user dashboard protected by session validation. Displays member profile cards, enrolled learning track, cohort progress metrics, mentor assignments, and quick actions.
  • Logout Functionality (logout.php): A security endpoint that safely ends user sessions by clearing memory variables, deleting browser cookies, and destroying session records on the server.
  • Standardized Copyright Footer (footer.php): Strictly implements the assignment copyright specification: © Alimatu Maliaka Jalloh, BSC(Hons) Software Engineering with Multimedia, Semester 5, 905004463, 2026.

3. Detailed Explanation of Design Choices, Plugins & Themes

A purposeful, modern design system was crafted specifically for Django Girls Sierra Leone. The interface prioritizes simplicity, professionalism, and a distinctive feminine aesthetic tailored to women in technology:

  • Feminine & Professional Color Palette: The visual theme is styled around a chic, modern feminine palette featuring rose-pink (#e11d48) and coral-pink (#fb7185) gradients as primary accents. This is paired with delicate rose-blush surfaces (#fff1f2, #faf8f9) and deep midnight-plum slate (#181124) for headers and cards, producing an empowering, sophisticated look that celebrates women in STEM.
  • Professional Vector SVG Icons (No Emojis): To maintain a high standard of professional visual hierarchy, all decorative OS emojis were replaced with crisp, lightweight inline SVG vector icons (calendar, map pin, sparkle, code, users, globe, shield, lock). This guarantees uniform rendering across all mobile, desktop, and operating system platforms.
  • Clean, Minimalist Layout Structure: Cards and containers feature balanced padding, smooth rounded borders (14px radius), soft shadows (box-shadow: 0 4px 10px rgba(225, 29, 72, 0.05)), and subtle borders (#fce7f3), avoiding visual clutter and keeping user attention focused on key actions.
  • Typography Strategy: The layout utilizes Plus Jakarta Sans and Tahoma as the primary font stack, guaranteeing high legibility, clean geometric letterforms, and full compliance with assignment font guidelines. An accent script font (Caveat) is selectively applied to the logo badge to maintain the community's signature warmth.
  • Feedback & Interactive Micro-Animations: Adhering to Human-Computer Interaction principles, form inputs feature glowing focus indicators, password fields include interactive visibility toggles, and live feedback indicators notify users when passwords match during registration.

4. Technical Implementation & Security Considerations

The platform strictly demonstrates core technical proficiencies from Weeks 1 to 4 of the Web Programming curriculum:

  • Password Hashing (password_hash & password_verify): In strict accordance with modern security standards, plaintext passwords are never stored. Upon registration, user passwords are encrypted using PHP's native password_hash($password, PASSWORD_DEFAULT), generating a secure 60-character bcrypt hash with automated cryptographic salting. Authentication is handled safely via password_verify().
  • SQL Injection Defense (PDO Prepared Statements): All interactions with the MySQL database utilize PHP Data Objects (PDO) with parameterized queries. Dynamic inputs are cleanly separated from SQL commands, completely neutralizing SQL injection risks.
  • Session Fixation & Hijacking Prevention: Following successful authentication, session_regenerate_id(true) is invoked to refresh the session token and discard old IDs. Session variables securely persist the user's ID, username, and learning track across protected views.
  • XSS Attack Prevention: All data retrieved from the database or user input is sanitized through htmlspecialchars() prior to HTML rendering.
